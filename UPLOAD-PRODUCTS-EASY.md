# Upload all products in about 5 minutes

1. Log in at your staff address (https://staff.yourdomain) with password + 6-digit code.
2. Admin > Products > **Bulk import**.
3. Choose `sportiq-products-ready.xlsx` (it has the photo paths) and, in "Photos folder", choose the folder that holds your product photos (the one with the `..._0.webp` files).
4. Click **Check file** (nothing is saved). Fix anything it lists.
5. Click **Import**. The browser then uploads the photos 4 at a time. If it stops, repeat; finished products are skipped.

Starting fresh? Admin > Products > tick all (top box) > **Delete ticked**, or type DELETE and press **Delete ALL products**.

Fan / Player Version: every football product shows both choices. Player Version adds the amount in Admin > Settings > "Player Version extra" (400 LKR).

## Photos not connecting? Check these
- In "Photos folder" pick the folder that CONTAINS the .webp/.jpg files (for you: `...\sportiq\images\uncategorized`), or any parent of it.
- Choose the folder BEFORE pressing "Check file". The check shows "Photos: X of 43 products have a matching image".
- Photos match by folder name + file name, so do not rename the files.
- Up to 5 photos per product are uploaded (main + 4).

## Bulk edit (Admin > Products)
Tick products, then: Set versions (Fan & Player / Fan only / Player only), Set price, Name/number/patches ON/OFF, Publish, Hide, Delete.
