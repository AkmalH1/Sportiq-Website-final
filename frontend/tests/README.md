# End-to-end tests (Playwright for Python)
`pip install playwright && playwright install chromium`
Start a FRESH server first (`rm -rf data`, then `npm run build && npm start -- -p 3077` with `ADMIN_PASSWORD_HASH=$(node scripts/hash-password.mjs test-password-12345) SPORTIQ_E2E=1 ADMIN_TOTP_SECRET=KRSXG5CTMVRXEZLUKRSXG5CTMVRXEZLU SESSION_SECRET=testsecret1234567890-abcdefghijkl BANK_NAME=TestBank BANK_ACCOUNT_NAME=SPORTIQ BANK_ACCOUNT_NUMBER=123456`), then run `python3 tests/e2e/e2e2.py`, `e2e3.py`, `e2e4.py`.
`e2e5.py` and `e2e6.py` (PayHere, late payments, lockout) need a fresh server on port 3078 with `PAYHERE_MERCHANT_ID=1200001 PAYHERE_MERCHANT_SECRET=testsecret`.
`audit.py <product-slug>` checks horizontal overflow at 320/375/390/768/1440px and small touch targets.
Each script prints PASS/FAIL lines; any FAIL is a bug.

New suites: `e2e9.py` (PayHere independent verification against a mock Retrieval API; run with `bash tests/e2e/run-e2e9.sh`), `e2e10.py` (authenticator-code login, replay, no lockout DoS; `bash tests/e2e/run-e2e10.sh`), `csp.py` (strict nonce CSP, real policy enforced), `tests/unit/ratelimit.concurrency.mjs` (200 simultaneous requests against the atomic limiter; needs the database), `node --experimental-strip-types --test tests/unit/*.test.ts` (TOTP vectors).
Two-factor is MANDATORY on every production-mode server (`next start`), including test servers: `ADMIN_MFA_OPTIONAL` is ignored when NODE_ENV=production and its presence is a configuration error. The e2e scripts log in with a code from `tests/e2e/totp_helper.py` (server started with `ADMIN_TOTP_SECRET=KRSXG5CTMVRXEZLUKRSXG5CTMVRXEZLU`). `SPORTIQ_E2E=1` (honoured only when SITE_URL is localhost) lets a test server start although the production config check (`lib/env-check.ts`) would reject its fake secrets. The e2e10 suite uses its own secret and no flag.
Unit tests added with the security pass: host-policy, request-guard, client-ip, env-check, payhere-logic, upload-retention (`node --experimental-strip-types --test tests/unit/*.test.ts`). `node --experimental-strip-types tests/unit/payhere.concurrency.mjs` races 30 callbacks against the throwaway test DB (creates and deletes fake rows).
